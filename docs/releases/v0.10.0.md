## ZAPX 0.10.0 — Reliability, triggers & tab polish

A big release across three fronts.

### 🔌 Connection reliability

- **SSH keepalive** — a configurable server-alive interval (default 60s, in
  Settings → SSH) keeps idle sessions from being dropped by firewalls/servers,
  and lets ZAPX detect a dead link quickly.
- **Reconnect on drop** — when the link goes down, the pane shows a
  **"Connection lost"** banner with a one-click **Reconnect**, and
  **auto-reconnect** retries with backoff (2s→15s) when enabled. The same
  terminal and scrollback are kept.

### 🎯 Output triggers

- Per session, define **triggers**: when a **pattern** (literal or regex)
  appears in the output, fire an action —
  - **notify**: pop a toast,
  - **send**: type text + Enter back to the session (great for auto-answering
    prompts),
  - **bell**: ring the terminal bell.
- Edited in the New/Edit Session dialog. A short per-trigger cooldown prevents
  a "send" action from looping on its own echo.

### 🗂 Tab & session UX

- **Double-click** a tab to rename it.
- **Right-click** a tab → **Duplicate** (re-opens with the same parameters) or
  pick a **colour** (shown as a left accent stripe).
- New terminal toolbar buttons: **⟳ reconnect**, **⌫ clear scrollback**, and
  **⭳ save output to file**.

### ⚠️ macOS: "ZAPX is damaged and can't be opened"

The macOS bundles are not signed/notarized. After dragging the app to
Applications, run `xattr -cr /Applications/ZAPX.app` — or right-click →
**Open** on first launch.
