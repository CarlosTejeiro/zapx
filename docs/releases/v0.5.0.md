## ZAPX 0.5.0 — Fleet workflows & migrating in

### ✨ New

- **Multi-send on any tab** — toggle multi-exec (`Ctrl+Shift+M`) on a normal
  split tab and the master input bar broadcasts everything you type to every
  live pane, not just grid tabs.
- **Send a command list to many sessions** — Tools → *Send command list…*:
  paste a runbook (one command per line, `#` comments skipped), pick the
  target sessions across all tabs, set a pause between lines, and fire it with
  live progress and a cancel button. SecureCRT "command window" style.
- **Import from PuTTY, MobaXterm and SecureCRT** (File menu), on top of the
  existing `~/.ssh/config` import — all idempotent (existing items skipped):
  - **PuTTY** — a `.reg` export anywhere, or the live registry on Windows.
  - **MobaXterm** — `MobaXterm.ini` / `.mxtsessions`, rebuilding its folders.
  - **SecureCRT** — its `Config/Sessions` folder tree.
- **Customizable button bar** — the bottom bar is now a SecureCRT-style button
  bar: create buttons inline with `+`, edit/delete on hover, and give each an
  accent color. The first nine still fire with `Ctrl+Shift+1..9`.

### 🔤 Changed

- The interface is now fully in **English** (some dialogs and toasts were
  previously in Spanish).

### ⚠️ macOS: "ZAPX is damaged and can't be opened"

The macOS bundles are not yet signed/notarized. After dragging the app to
Applications, run `xattr -cr /Applications/ZAPX.app` — or right-click →
**Open** on first launch.
