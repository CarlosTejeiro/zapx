## ZAPX 0.9.3 — Terminal copy keeps line breaks

### 🐛 Fixed

- **Copying from the terminal no longer flattens multi-line text on Linux.**
  Selecting several lines (e.g. a device's `show run interface`) and pasting
  into an editor, email, etc. used to land everything on a single line on
  Linux/WebKitGTK — the browser clipboard API drops the newlines there. ZAPX
  now copies through Tauri's native clipboard, which keeps the line breaks. No
  change on macOS/Windows (same native path, with the browser API as a
  fallback).

### ⚠️ macOS: "ZAPX is damaged and can't be opened"

The macOS bundles are not signed/notarized. After dragging the app to
Applications, run `xattr -cr /Applications/ZAPX.app` — or right-click →
**Open** on first launch.
