## ZAPX 0.10.3 — Snippet focus fix

### 🐛 Fixed

- **Typing after a snippet/button now works.** Firing a command button or
  snippet that doesn't end in a newline — e.g. `ps -aux | grep ` that you mean
  to finish typing yourself — left keyboard focus on the button (or the
  variable-prompt dialog), so what you typed next went nowhere. ZAPX now returns
  focus to the terminal right after sending the snippet.

### ⚠️ macOS: "ZAPX is damaged and can't be opened"

The macOS bundles are not signed/notarized. After dragging the app to
Applications, run `xattr -cr /Applications/ZAPX.app` — or right-click →
**Open** on first launch.
