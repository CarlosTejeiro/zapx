## ZAPX 0.10.1 — Search fixes

### 🐛 Fixed

- **In-terminal search (`Ctrl+F`)** — the match counter could read **"No
  results"** even when the word was clearly on screen, and after stepping
  **next** then **previous** the highlight could land on the wrong match. Both
  were caused by the search addon's debounced match-decoration system. ZAPX now
  counts matches itself (so the counter is always accurate) and uses xterm's own
  selection to mark the active match, so navigation is clean.

  Trade-off: matches are no longer all highlighted simultaneously — only the
  active match is selected as you step through them.

### ⚠️ macOS: "ZAPX is damaged and can't be opened"

The macOS bundles are not signed/notarized. After dragging the app to
Applications, run `xattr -cr /Applications/ZAPX.app` — or right-click →
**Open** on first launch.
