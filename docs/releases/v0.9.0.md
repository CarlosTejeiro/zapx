## ZAPX 0.9.0 — MobaXterm tunnels & Arch packaging

### ✨ New

- **Import MobaXterm port forwards** — the `[PortForwarding]` tunnels in a
  MobaXterm `.mobaconf`/`.ini` now import alongside your bookmarks. Each tunnel
  (Local / Dynamic / Remote) is attached to its SSH gateway — matched to an
  imported bookmark when one fits, otherwise a session is created for the
  gateway — so the forwards auto-start when you connect. (PuTTY tunnels already
  imported; SecureCRT is still pending a sample file.)
- **Arch Linux package** — a from-source `PKGBUILD` lives under
  `packaging/arch/`. On Arch, `makepkg -si` builds and installs ZAPX
  (`/usr/bin/zapx` + icon + launcher). It pulls the private repo over SSH at
  the release tag, so it's for your own and collaborators' machines, not the
  public AUR.

### 🔧 Changed

- Release bodies now carry the version's **CHANGELOG section** automatically,
  appended after these notes.

### ⚠️ macOS: "ZAPX is damaged and can't be opened"

The macOS bundles are not signed/notarized. After dragging the app to
Applications, run `xattr -cr /Applications/ZAPX.app` — or right-click →
**Open** on first launch.
