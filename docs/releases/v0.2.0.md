## ZAPX 0.2.0 — Full UI redesign

### ✨ New

- **New «Tile» app icon** and a unified SVG icon set across the whole UI.
- **7 themes** with full terminal ANSI palettes: Parchment, Oxide, Fjord,
  Nocturne, Porcelain, Phosphor and Amber (the CRT pair glows).
- **Redesigned chrome** — title bar, sidebar, tabs and status bar rebuilt on
  a consistent design system; the terminal now floats as a rounded card.
- **Bundled fonts** — Geist and JetBrains Mono ship with the app.

### ⚠️ macOS: "ZAPX is damaged and can't be opened"

The macOS bundles are not yet signed/notarized. After dragging the app to
Applications, run `xattr -cr /Applications/ZAPX.app` — or right-click →
**Open** on first launch.
