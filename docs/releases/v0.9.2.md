## ZAPX 0.9.2 — Linux CPU fix (for real this time)

### 🐛 Fixed

- **High CPU on Linux now actually fixed.** 0.9.1 tried to disable WebKitGTK's
  DMABUF renderer (the cause of WebKitWebProcess pinning a CPU core on NVIDIA /
  Wayland) by setting `WEBKIT_DISABLE_DMABUF_RENDERER=1` from inside the app —
  but that runs after WebKit has already started, so it had no effect. You had
  to launch with `WEBKIT_DISABLE_DMABUF_RENDERER=1 zapx` by hand.

  ZAPX now re-execs itself once at startup with the variable already in the
  environment, so WebKit picks it up from the very first moment — exactly like
  setting it in the shell, but automatic. Linux-only, and skipped if you've
  already set the variable yourself.

If you were running 0.9.1 with the workaround, you can drop it — 0.9.2 does it
for you.

### ⚠️ macOS: "ZAPX is damaged and can't be opened"

The macOS bundles are not signed/notarized. After dragging the app to
Applications, run `xattr -cr /Applications/ZAPX.app` — or right-click →
**Open** on first launch.
