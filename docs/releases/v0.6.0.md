## ZAPX 0.6.0 — Tunnels that stick & hints that learn

### ✨ New

- **Saved port forwards, auto-started on connect** — SSH sessions can now
  carry `-L` (local), `-D` (dynamic SOCKS5) and `-R` (remote) tunnels, set up
  in the New/Edit Session dialog. They open automatically every time the
  session connects, just like SecureCRT/MobaXterm "Port Forwarding". A forward
  that can't bind (port in use) is skipped with a log line, never killing the
  connection. Forwards travel with export/import too.
- **Smarter hints — command-sequence learning** — ZAPX learns which command
  you usually run right after another (per platform) and floats it to the top
  of the hint popup the moment you start typing it: after `configure terminal`,
  `interface …` leads, marked with a "usual next" badge. It's a local
  heuristic over your own history — no telemetry — and clearing your command
  history clears what it learned.
- **SFTP & Tunnels back in reach** — both buttons now live in each connected
  SSH pane's header. (The 0.2 redesign had hidden the old toolbar that held
  them, so they'd been unreachable in the UI.)

### 🐛 Fixed

- The New/Edit Session dialog now caps to the window and scrolls (with a
  sticky Cancel/Save), instead of overflowing off-screen.
- A startup crash on brand-new macOS builds: cosmetic window effects can no
  longer abort launch.

### ⚠️ macOS: "ZAPX is damaged and can't be opened"

The macOS bundles are not yet signed/notarized. After dragging the app to
Applications, run `xattr -cr /Applications/ZAPX.app` — or right-click →
**Open** on first launch.
