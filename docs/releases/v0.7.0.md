## ZAPX 0.7.0 — Button bar, snippet variables & tunnel control

### ✨ New

- **Drag to reorder the button bar** — arrange the bottom-bar buttons however
  you like; the order sticks, so you can deliberately pin the first nine
  (`Ctrl+Shift+1..9`).
- **Snippet variables** — put `{{name}}` placeholders in a snippet/button
  (optional default with `{{name=Default}}`). Running it asks for the values,
  then fills them in and sends. Reusable command templates.
- **Import PuTTY tunnels** — PuTTY's saved port forwards now come across on
  import and auto-start when the session connects.
- **Active tunnels manager** (Tools → *Active tunnels…*) — see every running
  port-forward across all your sessions at a glance, and stop any of them.

### ⚠️ macOS: "ZAPX is damaged and can't be opened"

The macOS bundles are not signed/notarized. After dragging the app to
Applications, run `xattr -cr /Applications/ZAPX.app` — or right-click →
**Open** on first launch.
