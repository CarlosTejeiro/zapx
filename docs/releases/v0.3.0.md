## ZAPX 0.3.0 — Portable & your data, your folder

### ✨ New

- **Portable Windows executable** — grab `ZAPX_x64_portable.exe`, drop it in
  any folder or USB stick and run it. No installation. To make it fully
  self-contained, create an empty file named `portable` next to the exe:
  sessions, settings, snippet catalogs and logs then live in a `data/`
  folder beside it and travel with the binary. *(Requires the WebView2
  runtime — preinstalled on Windows 11 and updated Windows 10.)*
- **Choose where your data lives** — **Settings → Data** shows where ZAPX
  keeps its database, logs and catalogs, and can migrate everything to any
  folder you pick (e.g. a synced drive). Power users can force a location
  with the `ZAPX_DATA_DIR` environment variable or the `--data-dir` CLI flag.
- **Window memory** — ZAPX now remembers your window size, position and
  maximized state. The first launch opens centered at 75 % of your monitor
  instead of a fixed 1200×800.

### 🔐 Security note for portable mode

In portable mode credentials are stored AES-256-GCM-encrypted inside the
database instead of the OS keyring, so the folder works across machines.
Anyone with access to the folder can use them — treat it like a physical key.

### ⚠️ macOS: "ZAPX is damaged and can't be opened"

The macOS bundles are not yet signed/notarized. After dragging the app to
Applications, run `xattr -cr /Applications/ZAPX.app` — or right-click →
**Open** on first launch.
