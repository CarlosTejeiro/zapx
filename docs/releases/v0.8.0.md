## ZAPX 0.8.0 — Regex logins & edit-in-place SFTP

### ✨ New

- **Regex in login automation** — a login step's *expect* can now be a regular
  expression (toggle the `.*` box per step). Matches against the cleaned
  output, so prompts like `[\w.-]+[#>]\s*$` just work. Invalid patterns fall
  back to a literal match.
- **Edit remote files over SFTP** — pick a file in the SFTP browser and hit
  **Edit**: ZAPX downloads it, opens it in your default editor, and uploads
  every save back to the server automatically until you close the session. No
  more download → edit → re-upload by hand.

### ⚠️ macOS: "ZAPX is damaged and can't be opened"

The macOS bundles are not signed/notarized. After dragging the app to
Applications, run `xattr -cr /Applications/ZAPX.app` — or right-click →
**Open** on first launch.
