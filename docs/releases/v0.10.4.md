## ZAPX 0.10.4 — Jump hosts, login scripts & a wider dialog

### 🐛 Fixed

- **Jump hosts now connect.** The strict host-key check refused any key not
  already in `known_hosts`. A host reachable only *through* a bastion can't be
  verified by the UI prompt (there's no direct route to it), so its key — and
  the bastion's — was never trusted, and every jump-host connection was
  rejected. Host keys are now **Trust-On-First-Use**: an unknown key is recorded
  and accepted on first connect, while a **changed** key is still rejected
  (MITM protection). Direct connections behave exactly as before.
- **Login scripts no longer stall.** Each step's *send* now presses **Enter**
  automatically (unless you already ended the line), so a step like `enable`
  actually runs. Previously the text was typed but never submitted, so the next
  step's *expect* never appeared.

### 🔧 Changed

- **Wider session dialog** — the New/Edit Session form is laid out in **two
  columns** (wider and shorter) instead of one tall vertical stack. It collapses
  back to a single column on narrow windows.

### ⚠️ macOS: "ZAPX is damaged and can't be opened"

The macOS bundles are not signed/notarized. After dragging the app to
Applications, run `xattr -cr /Applications/ZAPX.app` — or right-click →
**Open** on first launch.
